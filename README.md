# Regime-Dependent Active Inference

This repository contains technical memoranda and supporting materials associated with the **Regime-Dependent Active Inference** project at the **Active Inference Institute**.

**Project Lead:** Martin Bello

## Project Overview

Regime-Dependent Active Inference investigates extensions of Active Inference in which an agent's generative model, beliefs, policies, and behavior may depend upon transitions among distinct dynamical or behavioral regimes.

The repository provides a persistent public archive for technical memoranda documenting the theoretical development, mathematical formulation, computational implementation, and results of the project.
